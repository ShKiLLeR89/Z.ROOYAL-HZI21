مشکلات رایج

❌ نمی‌تونم به سرور وصل بشم +

• IP سرور رو دقیقاً چک کن: HZI21.aternos.me

• مطمئن شو اینترنتت وصله

• نسخه ماینکرفتت رو چک کن (باید با نسخه سرور هماهنگ باشه)

• اگه سرور آنلاین نیست، توی کانال تلگرام چک کن

🐌 بازی خیلی کند و لگ داره +

• تنظیمات گرافیکی بازی رو کم کن (Render Distance, Graphics)

• از کلاینت‌های سبک مثل Feather استفاده کن

• برنامه‌های پس‌زمینه رو ببند

• اگه مشکل ادامه داشت، از کلاینت‌های بهینه‌شده استفاده کن

🔐 چطور ثبت‌نام کنم؟ +

• بعد از ورود به سرور، توی چت دستور /register رمز رمز_تکرار رو بزن

• بعد از ثبت‌نام، هر بار ورود باید با /login رمز وارد بشی

• رمزت رو قوی انتخاب کن و یادت باشه

📱 روی موبایل چطور بازی کنم؟ +

• از میهن کرافت یا PojavLauncher استفاده کن

• تنظیمات کنترل لمسی رو یاد بگیر

• برای PvP، استفاده از گیم‌پد یا کیبورد بی‌سیم توصیه می‌شه

🎮 چه نسخه‌ای از ماینکرفت لازمه؟ +

• HZI21 از نسخه‌های 1.20 تا 1.21 پشتیبانی می‌کنه
